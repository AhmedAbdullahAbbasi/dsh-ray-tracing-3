# WD01/D03 Mie and forward ADT

This milestone adds an offline dust producer and portable runtime tables using
the preferred WD01 Milky Way R_V=3.1, b_C=60 ppm, case A size law (equations
2–6 and rounded Table 1 coefficients), with pinned Draine (2003) optical
constants. The accepted MRN/RG and RefleX providers and simulation default
retain their existing coefficients.

## Physical conventions

| Choice | Convention |
| --- | --- |
| Population | Literal rounded WD01 Table 1 law, 3.5 Angstrom to 2 microns |
| Normalization | Original per-H numbers; optional `d03_0p93` multiplies by 0.93 |
| Additional scaling | Explicit, separate carbon/silicate factors; never automatic |
| Grains | Homogeneous graphite and astronomical-silicate spheres |
| Graphite | Cross sections averaged 1/3 parallel + 2/3 perpendicular |
| Exact solver | `miepython==3.3.0`, unpolarized Mie amplitudes and efficiencies |
| Hybrid | Mie totals, restricted forward ADT, complete Mie tails |
| Absorption | Grain Q_abs = Q_ext − Q_sca from the same optical constants |
| Supported energies | 2–10 keV, no extrapolation |

Carbon optics use **bulk graphite at all sizes**, not the full PAH molecular
model. The source graphite table is for a 0.1-micron reference grain; no separate
radius-dependent dielectric prescription is added. Large grains dominate X-ray
scattering, but this does not validate every small-grain absorption feature.
The named 0.93 variant rescales this literal size law; it does not claim exact
agreement with the author's later updated extinction-curve files. No amplitude
fit to RefleX or extinction curves is applied.

WD01 mass conventions use graphite/silicate densities 2.24/3.5 g/cm3, whereas
D03 X-ray optical constants assume 2.2/3.8 g/cm3. Both inventories are reported.
The size law stays fixed; chemical declarations for these optics use **D03
densities**. Integrated volumes are 2.260e-27 and 3.957e-27 cm3/H, within 0.5%
of the rounded published volume columns.

**Nominal WD01 exceeds Wilms abundances.** D03-density solids require roughly
249 ppm C and 52.6 ppm each of Mg, Fe and Si; Wilms supplies 240 ppm C and
18.6 ppm Si. That pairing fails before generation. No implicit rescaling is
allowed. The nominal bank therefore declares a grain inventory without claiming
a complete ISM abundance set. A justified total vector or explicitly changed
grain normalization is needed before adding matching residual gas and H2.

```powershell
python -m scripts.generate_wd01_tables --audit-only
# Expected to fail the elemental budget:
python -m scripts.generate_wd01_tables --audit-only --abundances wilm
```

## Numerical contract

Raw Wiscombe amplitudes become dC/dOmega=(|S1|^2+|S2|^2)/(2 k^2), k in cm^-1.
Gauss integration in log radius weights the actual dn/da per H. Orientation
weights apply to cross sections, never to refractive indices.

Opt-in ADT requires x>=300, |m−1|<=0.01, |2x(m−1)|<=8 and theta<=0.1 radians.
It uses the corrected transverse argument x sin(theta). Mie supplies all totals,
outer angles and grains outside these bounds. Extending planar ADT to pi would
create a spurious backward peak. Large-q shadow integrals use analytic Bessel
moments, checked against independent adaptive quadrature.

Each component's raw angular integral must agree with its independent Mie total
within 0.3% **before** the small angular correction is applied. The final law,
total and CDF then share one normalization. Omitted negligible phase nodes have
a recorded summed probability bound below 1e-10; totals include every node.

The bundled `dsh/data/materials/wd01_d03_v1/` bank has 153 energies, 1,153
angles, hybrid scattering and radius order 12 per interval. The grid retains
native optical samples (including Fe K), adds a 0.1-keV scaffold and comparison
nodes, and remains increasing after float32 casting. Native samples close to
scaffold nodes are retained. Metadata include source/data hashes, solver versions,
both mass inventories, domain bounds and raw closure; diagnostics include
component laws and independently integrated Mie totals.

```python
from pathlib import Path
import dsh
from dsh.physics.wd01_tables import load_wd01_dust_tables
directory = Path(dsh.__file__).parent / "data/materials/wd01_d03_v1"
scattering, grain_absorption = load_wd01_dust_tables(directory)
```

Runtime loading needs only the existing NumPy/JAX dependencies. Absorption
explicitly covers **grains only**; the declared full-material builder still
requires atomic gas and H2. Adding full-ISM TBabs/TBnew to this grain term would
double-count solid absorption. Transport already adds scattering and absorption
to form extinction before and after scattering.

Native sampled edge structure is retained, but dedicated edge-segmented
interpolation and spectral-folding validation remain the next milestone.
This dust bank is not yet a complete ISM replacement for spectral fitting.

## Reproduce

```powershell
python -m pip install -e ".[materials,dev]"
$env:MIEPYTHON_USE_JIT = "1"
python -m scripts.generate_wd01_tables `
  --output dsh/data/materials/wd01_d03_v1 `
  --method mie_adt --quadrature-order 12 `
  --forward-nodes 1024 --tail-nodes 128 --workers 2
python -m scripts.generate_wd01_tables `
  --output benchmarks/materials/wd01_2026-10-16/full_mie_reference `
  --method mie --energies 2 3.3 4.9 6.9 10 `
  --quadrature-order 24 --forward-nodes 2048 --tail-nodes 512
python -m scripts.validate_wd01_tables `
  --reference benchmarks/materials/wd01_2026-10-16/full_mie_reference `
  --output benchmarks/materials/wd01_2026-10-16 `
  --transport-smoke --refine-reference-totals --plot
python -m unittest discover -v
```

`--plot` also needs Matplotlib (`.[benchmark]` includes it). Generation defaults
to full Mie unless hybrid is explicitly requested. JIT must be enabled before
importing miepython; it changes producer speed, not the runtime physics.

Predetermined comparison gates against the finer full-Mie reference are 0.1%
for scattering and grain absorption, 5e-4 absolute CDF error, and 1% relative
error in intrinsic angular bins with probability >=1e-4. These measure numerical
differences, not physical model uncertainty. Unit tests also check published
independent MIEV0 amplitudes, the analytic Rayleigh limit, ADT/Mie agreement,
size moments, cutoff convergence, optical samples/checksums and abundance audits.
The 8,192-history transport smoke deliberately uses grain-only absorption; it
checks integration and accounting, not full-ISM or RefleX agreement. The accepted
six-million-history RefleX compatibility regression is checked separately.

The reference totals receive another size-quadrature refinement from order 24
to 48, with a separate 1e-4 relative gate. The phase grid is not recomputed in
that additional totals-only check. Generated source fingerprints refer to the
producer implementation commit recorded in the saved verification summary.

All numerical gates and the 8,192-history production integration check pass.
There are no active, capped or invalid histories. The old six-million-history
RefleX statistics reproduce exactly, with all 63 accepted package checksums
unchanged. The built wheel includes all nine new optical/material data files
byte-for-byte and loads the production bank without miepython installed.
Detailed reports, source fingerprints, full-suite log, and a comparison figure
are in `wd01_2026-10-16/`. These checks do not establish an external WD01 halo
benchmark or high-resolution edge accuracy.

Its checksum manifest normalizes CRLF to LF for `.py`, `.json`, `.md`, `.toml`,
`.log` and `.gitattributes` text, so Windows checkouts remain verifiable. Optical
`.dat` files and binary files use exact byte checksums; pinned author data retain
their original whitespace.
